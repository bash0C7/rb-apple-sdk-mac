## 1. Thesis & Principles

### 1.1 Thesis

v1.2 で 「`AppleSDKMac.bootstrap!` 1 行で macOS public framework 全域、 `Apple.discover` は escape hatch」 の API thesis は完成した。 完成時点で現実の code に積もった **「過去経緯のコメント」 「Phase/T マーカー」 「v1.0→v1.5 changelog」 「dead schema column」 「unused module」 「empty placeholder file」 「parallel test files」** を客観的に削ぎ落とし、 *最新の現実だけが見える* 状態に揃える。

これは feature add でなく **simplification + honest-current-state** branch。 user-facing API surface は変えない。

### 1.2 Six principles

1. **最新の現実だけ写す** — 過去 phase / TDD task ID / "previously" / "Bug X fix" 形のコメントは削除。 history は `git log` が持つ
2. **浅 layer** — 1-method facade、 empty Hash placeholder、 1-file 1-dir wrapper、 dead Error class 再宣言は flatten / 削除
3. **dead schema は schema v4 から落とす** — 書かれない column (`cf_create_rule`, `objc_kind`, `swift_kind`)、 placeholder table (`symbols_vec`) は削除。 書かない code は書ける code 並みに dead
4. **test の cost も最新に揃える** — 50 min 走る real-SDK ingest test は post-rebuild assertion に再形成、 fresh ingest は 1 回だけ
5. **README L8 commitment は揺らがず** — release_quality 全 example 透過、 escape demo 1 個。 commitment は v1.2 と同じ
6. **silent rescue 全廃** — `rescue ... => _` / `rescue StandardError; nil` / 裸 `rescue` は warn + class-limited に置換 (global CLAUDE.md rule)

### 1.3 Tenet

> **「最新だけあればいい」 の徹底**。 後付け phase tag / 「v1.0→v1.5」 履歴 / 廃止 path への defensive code を消し、 reading code が *current* の事実だけを語る状態にする。

### 1.4 Why now

memory rule: `project_core_thesis_long_term_improvement.md`「 長期改善 + safe 継続実行」 が gem 設計の北極星。 v1.2 で 後者 (safe 継続実行) は確保された。 本 branch は前者 (長期改善) を 「accumulated cognitive load の削減」 として翻訳する。 1 ファイル 1 責務 / 履歴コメント不在 / dead column 不在 が長期改善の質量。

## 2. Scope

### 2.1 In scope

- 全 sub-gem (lib/apple_sdk_mac, knowledge, mcp, irb, tooling) の comment scrub + dead code / dead schema / placeholder file 削除
- 4 件の file split (public_api.rb / template_generator.rb / llm_generator.rb / public_api 由来 logic)
- examples/ + test/ の重複 / scaffolding 残骸の整理
- `test_importer_integration` の post-rebuild assertion 化 (= **#36 release_quality 高速化** の本体)
- TemplateGenerator catalog に `[:opaque_ref, :cstring, :uint32] -> :opaque_ref` shape を追加 (= **#37 discover_escape coverage**)
- silent rescue 2 箇所 (`diagnostics.rb`, `llm_resolver.rb`) を warn 化
- ext/runtime.c の `Test` submodule env gate 化

### 2.2 Out of scope

- `swift_overlay` と `swift_interface_parser` の統合 (両者の regex grammar が semantically distinct、 別 spec)
- Foundation Models 実 embedder 実装 (今は zero-vec placeholder を消すだけ)
- HITL emitter improvement workflow の major rewrite (`cleanup_stale` 削除のみ)
- v1.3 の feature add
- 各 sub-gem の version bump
- public API surface change (`Apple.bootstrap!` / `Apple.discover` / `AppleSDKMac.*` の signature 維持)

## 4. New addition (#37 — discover_escape TemplateGenerator coverage)

### 4.1 RED test (intent-level, mechanism は plan で確定)

`test/integration/examples_smoke_test.rb` (3.7.2 で `examples_v12_e2e_test` をマージしたあと、 ここに統合)。 新 test method の **assertion intent**:

1. `examples/discover_escape.rb` が exit 0 + 期待する `box=<N>` 形を stdout に出す
2. compile が **static template path** で完結する (LLM fallback に落ちなかったこと)。 後者は `compile_history` table に `generator='template'` の row が当該 symbol に対して存在することで verify

実 SQL / API mechanism (CompiledGlueCache に query method 新設するか、 test 内で直 SQLite query するか) は writing-plans で確定する。 今は **assertion semantics** が確立してれば spec として十分。

### 4.2 GREEN

`lib/apple_sdk_mac/glue_compiler/template_generator.rb` の C function emit path に `params: [:opaque_ref, :cstring, :uint32]` shape の handling を catalog として追加。 既存 path で:

- `:opaque_ref` 引数: `Unmanaged<AnyObject>?.fromOpaque(...)` 経由の load
- `:cstring` 引数: Swift `String` への `withCString` block
- `:uint32` 引数: `UInt32(...)` cast
- return `:opaque_ref`: `Unmanaged.passRetained(.takeRetainedValue())` 経由 raw pointer

3.1.9 の `objc_marshalling.rb` 抽出後、 同 module の `cfunc_in_load` / `cfunc_return_lines` (もしくは equivalent) に対応する刷新を加える。

### 4.3 omit 解除

`examples_v12_e2e_test.rb#test_discover_escape_example_returns_box` の `omit "TemplateGenerator coverage..."` (memory `release_quality_completion_required.md` の "DEFERRED-line escape" 該当) を解除。 この test method は 3.7.2 で smoke test に統合される。
