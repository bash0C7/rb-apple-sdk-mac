# v1.2 — bootstrap! 原則 + Apple.discover 例外化 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** rb-apple-sdk-mac v1.2.0 として「`AppleSDKMac.bootstrap!` だけで Apple framework のあらゆる public API が透過 dispatch で叩ける」状態を完成させる。 spec: `docs/superpowers/specs/2026-05-09-v1.2-bootstrap-principle-design.md`

**Architecture:** 7 Phase 直列。 (0) project-scoped MCP wire → (1) knowledge を sub-gem に統合 → (2) LLM safety net + project-scoped cache → (3) IntMarshaller 静的化 → (4a) KB ingester に Swift overlay 追加 → (4b) emitter SwiftBridgeName 値オブジェクト + 単一 LLM retry 境界 → (5) examples 全 refactor → (6) 主 README 刷新 → (7) 旧 repo archive + delete。 `~/dev/src/CLAUDE.md` の TDD 規律 (RED→GREEN→REFACTOR を別 commit) を全 task で守る。

**Tech Stack:** Ruby 4.0.3 + RUBY_BOX=1, Swift 6.3+, swiftc, macOS 26 SDK, SQLite (via `rb_apple_sdk_knowledge`), Foundation Model (on-device via `rb-foundation-model-mac`), test-unit, screen detached, mcp gem, gh CLI.

**Long-running command policy:** `bundle exec rake test` 全走は subagent 経由 (`~/dev/src/CLAUDE.md` の Test Execution Delegation rule)。 `bundle exec rake apple:knowledge:rebuild` は `screen -dmS apple-sdk-26.2-ingest ...` detached pattern。 single-test focused run は Bash 直叩き可。

`lib/apple_sdk_mac/cache_dir.rb`:

```ruby
# frozen_string_literal: true
module AppleSDKMac
  class ProjectRootError < StandardError; end

  def self.cache_dir
    root = bundler_root || gemfile_walk_up
    raise ProjectRootError, "rb-apple-sdk-mac: project root を特定できません。 Gemfile / gems.rb のあるディレクトリで実行してください。" unless root
    File.join(root, ".rb-apple-sdk-mac")
  end

  class << self
    private

    def bundler_root
      return nil unless defined?(Bundler) && Bundler.respond_to?(:root)
      Bundler.root.to_s
    rescue StandardError
      nil
    end

    def gemfile_walk_up
      dir = Dir.pwd
      while dir != "/"
        return dir if File.exist?(File.join(dir, "Gemfile")) || File.exist?(File.join(dir, "gems.rb"))
        dir = File.dirname(dir)
      end
      nil
    end
  end
end
```

```ruby
class IntMarshaller < Marshaller
  def in_load
    return nil if @param[:is_out_param]
    "let #{@param[:name]}: Int64 = rb_num2ll(argv[#{@index}])"
  end

  def call_arg
    return "&#{@param[:name]}" if @param[:is_out_param]
    ctype = scalar_type_token(@param[:type])
    return @param[:name] if ctype.nil? || ctype == "Int64"
    "numericCast(#{@param[:name]})"
  end

  def out_handling
    return nil unless @param[:is_out_param]
    ctype = scalar_type_token(@param[:type]) || "Int64"
    {
      init: "var #{@param[:name]}: #{ctype} = 0",
      addr: "&#{@param[:name]}",
      to_ruby: unsigned?(@param[:type]) \
        ? "rb_ull2inum(UInt64(#{@param[:name]}))"
        : "rb_ll2inum(Int64(#{@param[:name]}))"
    }
  end

  private

  def scalar_type_token(raw)
    cleaned = raw.to_s.strip
                 .sub(/\Aconst\s+/, "")
                 .gsub(/\b_(Nonnull|Nullable)\b/, "")
                 .sub(/\s*\*+\s*\z/, "")  # 末尾 * を剥がす (out 用)
                 .strip
    return nil if cleaned.empty? || cleaned.include?("*")
    cleaned
  end

  def unsigned?(t)
    t.match?(/\b(UInt|UInt8|UInt16|UInt32|UInt64|uint(8|16|32|64)_t|unsigned)\b/)
  end
end
```

```ruby
module AppleSDKKnowledge
  module Importers
    class SwiftOverlay
      def initialize(store)
        @store = store
      end

      private

      def extract_extension_blocks(text)
        blocks = []
        scanner = StringScanner.new(text)
        until scanner.eos?
          unless scanner.scan_until(/extension\s+(\w+)\s*(?:\:[^{]+)?\{/)
            break
          end
          klass = scanner[1]
          body, depth = String.new, 1
          while depth > 0 && (ch = scanner.getch)
            depth += 1 if ch == "{"
            depth -= 1 if ch == "}"
            body << ch if depth > 0
          end
          blocks << { klass: klass, body: body }
        end
        blocks
      end
    end
  end
end
```

`swift_overlay.rb` に追加 (private):

```ruby
DECL_FUNC_RE = /\A\s*(?:open\s+|public\s+)+(class\s+func|static\s+func|func|init)\s+(\w+)?\s*\(([^)]*)\)\s*(?:->\s*(.+))?\z/
DECL_VAR_RE  = /\A\s*(?:open\s+|public\s+)+var\s+(\w+)\s*:\s*([^\{]+?)\s*\{[^\}]*\}\s*\z/

def parse_decl_line(line)
  if (m = line.match(DECL_FUNC_RE))
    kind_str, name, params_str, ret = m.captures
    kind = case kind_str.tr(" ", "_")
           when "class_func" then :class_func
           when "static_func" then :static_func
           when "func" then :func
           when "init" then :init
           end
    name ||= "init"
    {
      kind: kind, name: name,
      params: parse_params(params_str),
      return_type: ret&.strip
    }
  elsif (m = line.match(DECL_VAR_RE))
    name, type = m.captures
    { kind: :var, name: name, params: [], return_type: type.strip }
  end
end

def parse_params(s)
  return [] if s.strip.empty?
  s.split(",").map do |p|
    p = p.strip
    if p.match(/\A(\w+)\s+(\w+)\s*:\s*(.+)\z/)
      { label: $1, inner: $2, type: $3.strip }
    elsif p.match(/\A(\w+)\s*:\s*(.+)\z/)
      { label: $1, inner: $1, type: $2.strip }
    else
      { label: nil, inner: nil, type: p }
    end
  end
end
```

```ruby
def objc_selector_for(klass, decl)
  case decl[:kind]
  when :var
    decl[:name]
  when :init
    if decl[:params].empty?
      "init"
    else
      labels = decl[:params].map.with_index { |p, i| i == 0 ? "initWith#{capitalize(p[:label] || p[:inner])}" : p[:label] }
      labels.join(":") + ":"
    end
  when :class_func, :static_func, :func
    if decl[:params].empty?
      decl[:name]
    else
      first = "#{decl[:name]}With#{capitalize(decl[:params][0][:label] || decl[:params][0][:inner])}"
      rest = decl[:params][1..].map { |p| p[:label] }
      ([first] + rest).join(":") + ":"
    end
  end
end

def swift_imported_name_for(decl)
  case decl[:kind]
  when :var then decl[:name]
  when :init
    "init(#{decl[:params].map { |p| "#{p[:label]}:" }.join})"
  when :class_func, :static_func, :func
    "#{decl[:name]}(#{decl[:params].map { |p| "#{p[:label]}:" }.join})"
  end
end

def capitalize(s)
  s.sub(/\A./) { $&.upcase }
end
```

```ruby
def import!(framework:, path:)
  return unless File.exist?(path)
  text = File.read(path)
  framework_id = upsert_framework(framework)
  extract_extension_blocks(text).each do |block|
    parent_id = upsert_klass(framework_id, block[:klass])
    block[:body].each_line do |line|
      decl = parse_decl_line(line) or next
      upsert_decl(framework_id: framework_id, parent_id: parent_id, klass: block[:klass], decl: decl)
    end
  end

private

def upsert_framework(name)
  @store.db.execute("INSERT OR IGNORE INTO frameworks(name) VALUES (?)", [name])
  @store.db.execute("SELECT id FROM frameworks WHERE name = ?", [name]).first[0]
end

def upsert_klass(framework_id, name)
  @store.db.execute(<<~SQL, [name, framework_id])
    INSERT OR IGNORE INTO symbols(name, kind, framework_id, parent_id) VALUES (?, 'class', ?, NULL)
  SQL
  @store.db.execute("SELECT id FROM symbols WHERE name = ? AND framework_id = ? AND parent_id IS NULL", [name, framework_id]).first[0]
end

         when :var then "swift_property"
```

```ruby
# frozen_string_literal: true
require_relative "swift_bridge_overrides"

module AppleSDKMac
  class GlueCompiler
    class SwiftBridgeName
      def self.resolve(klass, selector, kc:, framework:)
        imported = from_kb(klass, selector, kc: kc, framework: framework) ||
                   from_override(klass, selector) ||
                   from_heuristic(klass, selector)
        return nil unless imported
        new(klass, imported)
      end

      def initialize(klass, imported_name)
        @klass = klass
        @imported = imported_name
      end

      def swift_call_expression(args)
        if @imported.start_with?("init")
          # init form: AVSpeechUtterance(string: arg0)
          labels = parse_labels(@imported)
          inner = labels.zip(args).map { |l, a| "#{l}: #{a}" }.join(", ")
          "#{@klass}(#{inner})"
        else
          # class method form: AVCaptureDevice.devices(for: arg0)
          method, labels = parse_method_and_labels(@imported)
          inner = labels.zip(args).map { |l, a| "#{l}: #{a}" }.join(", ")
          "#{@klass}.#{method}(#{inner})"
        end
      end

      private

      def parse_labels(imported)
        # "init(utf8String:)" → ["utf8String"]
        m = imported.match(/\((.+)\)\z/)
        return [] unless m
        m[1].split(",").map { |l| l.strip.delete_suffix(":") }
      end

      def parse_method_and_labels(imported)
        m = imported.match(/\A(\w+)\((.+)\)\z/)
        return [imported, []] unless m
        [m[1], m[2].split(",").map { |l| l.strip.delete_suffix(":") }]
      end

      def self.from_kb(klass, selector, kc:, framework:)
        return nil unless kc
        row = kc.lookup_klass_method(framework: framework, klass: klass, method: selector)
        row && row[:swift_imported_name]
      end

      def self.from_override(klass, selector)
        SWIFT_BRIDGE_OVERRIDES.dig(klass, selector)
      end

      def self.from_heuristic(klass, selector)
        # 既存 swift_call_for_class_method の `<verb>With<Type>:` 規則を移植 →
        # 戻り値は Swift import name 形 (`init(utf8String:)` / `devices(for:)` 等)
        # 詳細は移植先で実装
        nil
      end
    end
  end
end
```

# rb-apple-sdk-mac

> ⚠️ **This gem is experimental.** Ruby 4 Box (`RUBY_BOX=1`)、 macOS 26 Foundation Model on-device、 LLM 由来 glue の確率性、 v1.x 中の API shape 変更ありうる。 dogfood / 個人ツール / 検証用途を想定、 production 投入は推奨しません。

Runtime dynamic Ruby ↔ Apple SDK bridge for macOS. Call any public Apple framework API from Ruby with no pre-declarations.

## Principle

```ruby
require "apple_sdk_mac"
AppleSDKMac.bootstrap!

client = Apple::CoreMIDI.MIDIClientCreate("MyClient", nil, nil)
devices = Apple::AVFoundation::AVCaptureDevice.devicesWithMediaType("soun")
```

`bootstrap!` 1 行で Apple framework の public symbol すべてが Ruby method として
叩ける。 必要に応じて `Apple::<Framework>::<Klass>.<method>(...)` を呼ぶだけ。
事前宣言は不要。

## Six principles

1. **bootstrap! ファースト** — `bootstrap!` の後はどの API も透過 dispatch
2. **Apple.discover は exception** — KB 未収載 symbol の escape hatch だけ
3. **静的 emitter が高速 path** — KB に居る pattern は deterministic に Swift glue
4. **LLM safety net がカバー** — 静的 emit 不能な pattern は Foundation Model on-device 経由で自動生成、 「網羅 > 速度」
5. **examples は principle の例示** — `examples/*.rb` は bootstrap! 中心、 `discover_escape.rb` だけ escape demo
6. **experimental 自覚** — このバナー再掲、 v1.x の shape 変更ありうる
