### Observations for future iteration

- `apple:emitter:candidates` reads the SQLite path from
  `<project_root>/.rb-apple-sdk-mac/<SDK_VERSION>/cache.sqlite` — there is
  no env override for the SQLite location itself. Ad-hoc smokes need a
  throwaway `SDK_VERSION` directory.
- `apple:emitter:worktree_create` defaults its candidates input to
  `tmp/emitter/candidates.json`. Pair Step 2's `OUT=` with Step 3's
  `CANDIDATES=` if redirecting both.
- `WorktreeOps.populate_cache` creates `knowledge`/`sources`/`lib`
  symlinks unconditionally; if the source SDK version directory only
  contains a partial layout the links will be dangling. Real operator
  runs after `apple:knowledge:rebuild` do not hit this.
